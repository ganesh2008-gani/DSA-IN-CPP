# LeetCode DSA Solutions in C++

A collection of Data Structures and Algorithms (DSA) problems solved on LeetCode using C++. This repository helps me practice problem-solving, understand algorithms, and track my progress in DSA.

## 📚 Topics Covered

- **Arrays and Subarrays**
  - Maximum Subarray
  - Maximum Product Subarray
  - Maximum Sum Circular Subarray

- **Binary Search**
  - Binary Search
  - Search Insert Position
  - Find Peak Element
  - Search in Rotated Sorted Array

- **Sliding Window**
  - Max Consecutive Ones III

- **Stack**
  - Valid Parentheses

- **Prefix Sum**
  - Range Sum Query 2D - Immutable
  - Matrix Block Sum
  - Number of Submatrices That Sum to Target

- **Bit Manipulation**
  - XOR Queries of a Subarray
  - Maximum XOR for Each Query
  - Count Triplets That Can Form Two Arrays of Equal XOR
